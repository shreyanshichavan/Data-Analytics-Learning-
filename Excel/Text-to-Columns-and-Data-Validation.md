# Text to Columns & Data Validation

## 1. Text to Columns

**Text to Columns** is an Excel feature used to split combined data into separate columns.

### Example

If a column contains:

`Shreyanshi, Nagpur, Data Analyst`

It can be separated into:

| Name       | City   | Role         |
| ---------- | ------ | ------------ |
| Shreyanshi | Nagpur | Data Analyst |

**Why it is useful:**

* Organizes unstructured or combined data
* Makes data easier to analyze
* Helps prepare datasets for reporting and visualization

---

## 2. Data Validation

**Data Validation** is an Excel feature used to control what users can enter into a cell.

### Example

A department column can be restricted to:

`HR, Finance, IT, Sales, Marketing`

This helps prevent incorrect or inconsistent entries.

**Why it is useful:**

* Maintains data accuracy
* Reduces data-entry errors
* Improves consistency
* Keeps datasets clean and reliable

---

## 3. Key Takeaways

* **Text to Columns** → Splits and organizes combined data.
* **Data Validation** → Maintains accuracy and consistency.
* **Clean Data + Valid Data** → Creates a strong foundation for better analysis.

### Data Analytics Perspective

Before analyzing data, it is important to make sure the dataset is **structured, clean, accurate, and consistent**.

**Good Data → Better Analysis → Better Insights**
